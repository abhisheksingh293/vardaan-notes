Level 2 Worksheet: Algebraic Expressions (ICSE Class 7)
Student Name: ____________________________________ Class: VII (ICSE) Subject: Mathematics
Section A: Intermediate Terminology & Degree Analysis
1.
Find the degree of the multi-variable algebraic expression: $5x^4y^2 - 3x^3y^4 + 2xy^5 - 7$.
2.
Identify the coefficient of $x^2$ in the expansion of $(x - 3)(2x + 5)(x - 1)$. *(Hint: Multiply out or isolate terms)*
3.
Write the sum of the coefficients of all terms in the expression: $3x^3 - 5x^2 + 7x - 9$.
4.
If $A = 3x^2 - 5x + 2$, $B = -x^2 + 4x - 6$, and $C = 2x^2 - 3x + 5$, find $2A - B + 3C$.
5.
Write an algebraic expression for: "Three times the sum of $x$ and $y$ decreased by twice the product of $x$ and $y$."
6.
Determine whether the expression $\frac{3x^2 - 5x + 2}{x}$ is a polynomial. Give a brief reason.
7.
Find the literal coefficient and numerical coefficient of the term $-\frac{3}{4}a^3b^2c$.
8.
How many terms are there in the simplified form of $(x+y+z)^2$ after completely expanding and combining like terms?
9.
Classify the expression $x^2y - xy^2 + 3xy$ based on the number of terms and its total degree.
10.
If the degree of $px^a y^b$ is 7 and $a = 3$, find the value of $b$.
Section B: Advanced Value Substitution
11.
Evaluate $\frac{x^3 + y^3 + z^3 - 3xyz}{x + y + z}$ when $x = 2, y = 3, z = 4$.
12.
If $x - \frac{1}{x} = 3$, find the value of $x^2 + \frac{1}{x^2}$.
13.
Calculate the value of $2a^2b - 3ab^2 + 5abc$ when $a = -2, b = 3, c = -1$.
14.
Find the numerical value of $x^4 - 4x^3 + 6x^2 - 4x + 1$ when $x = 2$.
15.
If $p = 3, q = -2, r = 4$, evaluate $\frac{p^2 + q^2 - r^2}{pq + qr - rp}$.
16.
Evaluate $(2x - 3y)^2 - (2x + 3y)^2$ for $x = 5$ and $y = 2$.
17.
Find the value of $x^3 - 8y^3$ when $x = 4$ and $y = 1$.
18.
If $a + b + c = 10$ and $ab + bc + ca = 30$, find the value of $a^2 + b^2 + c^2$.
19.
Evaluate $\frac{a^3 - b^3}{a^2 + ab + b^2}$ when $a = 7$ and $b = 4$.
20.
Find the value of $5(x - 2)^2 - 3(x + 1) + 4$ when $x = 3$.
Section C: Addition, Subtraction & Bracket Simplification
21.
Subtract the sum of $2x^2 - 3x + 5$ and $-x^2 + 4x - 2$ from $5x^2 - 2x + 10$.
22.
Simplify the nested bracket expression: $3x - [5y - \{2x - (3x - 2y - z) + z\}]$.
23.
What expression must be subtracted from $4x^3 - 3x^2 + 5x - 1$ to obtain $3x^3 + x^2 - 2x + 7$?
24.
Simplify: $2a^2 - [3a - \{4a^2 - (2a - 3)\} + 5a]$.
25.
Add the product of $(x+2)$ and $(x+3)$ to the sum of $3x^2 - 5x + 1$ and $-x^2 + 2x - 4$.
26.
Simplify: $7xy - [3x^2 - \{2xy - (x^2 - 3xy)\} + 4y^2]$.
27.
What should be added to $2a^2 + 3ab - b^2$ to get $5a^2 - ab + 2b^2$?
28.
Simplify: $5x - [4x - \{3x - (2x - x)\}]$.
29.
Subtract $3m^2 - 4mn + 5n^2$ from the sum of $m^2 + mn - n^2$ and $2m^2 - 5mn + 4n^2$.
30.
Simplify: $2\{x - 3(y - x) + 4y\} - 3\{x + 2(y - x)\}$.
Section D: Advanced Multiplication & Identities
31.
Multiply the trinomial by a binomial: $(2x^2 - 3x + 5)(3x - 2)$.
32.
Find the product: $(3x - 2y)(3x + 2y)(9x^2 + 4y^2)$.
33.
Expand and simplify: $(2a + 3b - c)(2a - 3b + c)$ by grouping.
34.
Find the product of three binomials: $(x - 1)(x + 2)(x - 3)$.
35.
Simplify using algebraic identities: $(5x + 3y)^2 - (5x - 3y)^2$.
36.
Find the product: $(x^2 - xy + y^2)(x + y)$.
37.
Evaluate the continuous product: $(2x - 3)(2x + 3)(4x^2 + 9)$.
38.
Multiply: $\left(\frac{1}{2}x - \frac{1}{3}y\right)\left(\frac{1}{2}x + \frac{1}{3}y\right)$.
39.
Expand: $(3x - 2y + 4)^2$. *(Using trinomial square identity)*
40.
Simplify: $(x + y)(x^2 - xy + y^2) + (x - y)(x^2 + xy + y^2)$.
Section E: Division, Word Problems & Complex Simplification
41.
Divide the polynomial by a binomial: $(x^3 - 6x^2 + 11x - 6) \div (x - 1)$.
42.
Simplify: $\frac{12x^4y^3 - 18x^3y^2 + 24x^2y}{6x^2y}$.
43.
The side of a square field is represented by $(3x - 2) \text{ m}$. Find its perimeter and area as algebraic expressions.
44.
The length of a rectangle is $(5x + 3) \text{ cm}$ and its breadth is $(2x - 1) \text{ cm}$. Find its area when $x = 3$.
45.
Simplify completely: $4x[3x - 2(x - 3)] - 5x(2x - 1)$.
