SECTION A — SOLUTIONS (8 Marks)
(i) Value of $(103 \times 97)$ using algebraic identity.
[1 Mark]
Correct Option: (a) 9991
Express $103 \times 97$ as $(100 + 3)(100 - 3)$.
Using identity $(a + b)(a - b) = a^2 - b^2$:
$$\begin{aligned} (100 + 3)(100 - 3) &= 100^2 - 3^2 \\ &= 10000 - 9 \\ &= 9991 \end{aligned}$$
(ii) What percent of $250$ is $65$?
[1 Mark]
Correct Option: (c) 26%
Required Percentage $= \left( \dfrac{\text{Given Value}}{\text{Total Value}} \times 100 \right)\%$
$$= \left( \dfrac{65}{250} \times 100 \right)\% = \left( \dfrac{13}{50} \times 100 \right)\% = 26\%$$
(iii) Measured length $= 4.8\text{ cm}$, Actual length $= 5.0\text{ cm}$. Percentage Error?
[1 Mark]
Correct Option: (b) 4%
Error $= |5.0\text{ cm} - 4.8\text{ cm}| = 0.2\text{ cm}$
Percentage Error $= \left( \dfrac{\text{Error}}{\text{Actual Value}} \times 100 \right)\%$
$$= \left( \dfrac{0.2}{5.0} \times 100 \right)\% = \dfrac{20}{5}\% = 4\%$$
(iv) M.P. $= \text{₹}800$, Discount $= 15\%$. Find Selling Price.
[1 Mark]
Correct Option: (a) ₹680
Discount Amount $= 15\% \text{ of } 800 = \dfrac{15}{100} \times 800 = \text{₹}120$
$$\text{S.P.} = \text{M.P.} - \text{Discount} = 800 - 120 = \text{₹}680$$
(v) Solve $18 - 4(x - 1) = 2x + 4$.
[1 Mark]
Correct Option: (b) 3
$$18 - 4x + 4 = 2x + 4$$
$$22 - 4x = 2x + 4$$
$$22 - 4 = 2x + 4x \implies 6x = 18 \implies x = 3$$
(vi) Expansion of $(4a - 3b)^2$.
[1 Mark]
Correct Option: (b) $16a^2 - 24ab + 9b^2$
Using identity $(x - y)^2 = x^2 - 2xy + y^2$:
$$(4a - 3b)^2 = (4a)^2 - 2(4a)(3b) + (3b)^2 = 16a^2 - 24ab + 9b^2$$
(vii) Diagonals of a rectangle are:
[1 Mark]
Correct Option: (b) Equal and bisect each other
In any rectangle, diagonals are congruent (equal in length) and bisect each other at their midpoint.
(viii) Assertion (A) & Reason (R) on Rhombus.
[1 Mark]
Correct Option: (a) Both A and R are correct and R is the correct explanation of A.
Because all four sides of a rhombus are equal, its diagonals bisect each other perpendicularly at $90^\circ$. Hence, Reason (R) correctly explains Assertion (A).
SECTION B — SOLUTIONS (8 Marks)
1. Parallelogram $ABCD$ with $\angle A = (3x - 15)^\circ$ and $\angle B = (2x + 10)^\circ$. Find $x$ and all interior angles.
[2 Marks]
Step 1: Adjacent interior angles of a parallelogram sum up to $180^\circ$.
$$\angle A + \angle B = 180^\circ$$
$$(3x - 15) + (2x + 10) = 180 \implies 5x - 5 = 180 \implies 5x = 185 \implies x = 37^\circ$$
Step 2: Compute individual angle measures:
$$\angle A = 3(37) - 15 = 111 - 15 = 96^\circ$$
$$\angle B = 2(37) + 10 = 74 + 10 = 84^\circ$$
Since opposite angles are equal: $\angle C = \angle A = 96^\circ$ and $\angle D = \angle B = 84^\circ$.
Ans: $x = 37^\circ$; $\angle A = 96^\circ, \angle B = 84^\circ, \angle C = 96^\circ, \angle D = 84^\circ$.
2. Solve for $x$: $\dfrac{3x - 2}{5} = \dfrac{2x + 1}{4}$
[2 Marks]
Cross-multiplying both sides:
$$4(3x - 2) = 5(2x + 1)$$
$$12x - 8 = 10x + 5$$
$$12x - 10x = 5 + 8 \implies 2x = 13 \implies x = \dfrac{13}{2} = 6.5$$
Ans: $x = \dfrac{13}{2} \text{ or } 6.5$.
3. Evaluate using identity: $(1.5)^2 - (0.5)^2$.
[2 Marks]
Using identity $a^2 - b^2 = (a - b)(a + b)$ where $a = 1.5$ and $b = 0.5$:
$$(1.5)^2 - (0.5)^2 = (1.5 - 0.5)(1.5 + 0.5)$$
$$= (1.0) \times (2.0) = 2.0$$
Ans: $2.0$.
4. Evaluate: $25\%$ of $480 - 15\%$ of $200 + 10\%$ of $350$.
[2 Marks]
$$\text{Term 1} = \dfrac{25}{100} \times 480 = 120$$
$$\text{Term 2} = \dfrac{15}{100} \times 200 = 30$$
$$\text{Term 3} = \dfrac{10}{100} \times 350 = 35$$
$$\text{Final Value} = 120 - 30 + 35 = 125$$
Ans: $125$.
SECTION C — SOLUTIONS (12 Marks)
1. Net percentage change when price is increased by $25\%$ and then decreased by $20\%$.
[3 Marks]
Let original price $= \text{₹}100$.
Increase of 25%: Price $= 100 + \left(\dfrac{25}{100} \times 100\right) = \text{₹}125$.
Decrease of 20%: Final Price $= 125 - \left(\dfrac{20}{100} \times 125\right) = 125 - 25 = \text{₹}100$.
Net change $= 100 - 100 = \text{₹}0$.
$$\text{Net Percentage Change} = 0\%$$
Ans: No change in net price ($0\%$ net change).
2. S.P. $= \text{₹}1,840$ with $8\%$ loss. Find S.P. to gain $10\%$.
[3 Marks]
Step 1: Find Cost Price (C.P.)
$$\text{C.P.} = \dfrac{\text{S.P.} \times 100}{100 - \text{Loss}\%} = \dfrac{1840 \times 100}{92} = 20 \times 100 = \text{₹}2,000$$
Step 2: Find new S.P. for $10\%$ gain
$$\text{New S.P.} = \text{C.P.} \times \left(\dfrac{100 + \text{New Gain}\%}{100}\right)$$
$$\text{New S.P.} = 2000 \times \dfrac{110}{100} = 20 \times 110 = \text{₹}2,200$$
Ans: ₹$2,200$.
3. Factorise completely:
[6 Marks]
a) $x^3 - 2x^2 - 4x + 8$ [2 Marks]
Grouping in pairs:
$$= x^2(x - 2) - 4(x - 2) = (x - 2)(x^2 - 4)$$
$$= (x - 2)(x - 2)(x + 2) = (x - 2)^2(x + 2)$$
b) $9p^2 - 24pq + 16q^2 - 36r^2$ [2 Marks]
Recognising perfect square in first 3 terms:
$$= (3p - 4q)^2 - (6r)^2$$
Using $X^2 - Y^2 = (X - Y)(X + Y)$:
$$= (3p - 4q - 6r)(3p - 4q + 6r)$$
c) $(12y^2 - 27) \div (2y - 3)$ [2 Marks]
$$= \dfrac{3(4y^2 - 9)}{2y - 3} = \dfrac{3(2y - 3)(2y + 3)}{2y - 3}$$
Cancelling $(2y - 3)$:
$$= 3(2y + 3) \text{ or } 6y + 9$$
SECTION D — SOLUTIONS (12 Marks)
1. Age Problem: Father is 32 years older than son. In 8 years, father will be 3 times as old as son.
[4 Marks]
Let present age of son $= x$ years.
Present age of father $= x + 32$ years.
After 8 years:
Son's age $= x + 8$
Father's age $= x + 32 + 8 = x + 40$
According to question:
$$x + 40 = 3(x + 8)$$
$$x + 40 = 3x + 24 \implies 3x - x = 40 - 24 \implies 2x = 16 \implies x = 8$$
Present age of son $= 8$ years.
Present age of father $= 8 + 32 = 40$ years.
Ans: Son's age $= 8$ years, Father's age $= 40$ years.
2. Rhombus $ABCD$ with $\angle ODC = 40^\circ$. Find $\angle OCD, \angle ABC, \angle DAB$.
[4 Marks]
(i) Find $\angle OCD$:
Diagonals of a rhombus intersect at $90^\circ$, so $\angle DOC = 90^\circ$.
In $\triangle DOC$: $\angle OCD = 180^\circ - (90^\circ + 40^\circ) = 50^\circ$.
(ii) Find $\angle ABC$:
Diagonals bisect vertex angles, so $\angle ADC = 2 \times \angle ODC = 2 \times 40^\circ = 80^\circ$.
Opposite angles are equal: $\angle ABC = \angle ADC = 80^\circ$.
(iii) Find $\angle DAB$:
Adjacent angles are supplementary: $\angle DAB = 180^\circ - 80^\circ = 100^\circ$.
Ans: (i) $50^\circ$, (ii) $80^\circ$, (iii) $100^\circ$.
3. Goods marked $40\%$ above C.P. and $20\%$ discount allowed. Overall gain/loss percentage?
[4 Marks]
Let Cost Price (C.P.) $= \text{₹}100$.
Marked Price (M.P.) $= 100 + 40\% \text{ of } 100 = \text{₹}140$.
$$\text{Discount} = 20\% \text{ of M.P.} = \dfrac{20}{100} \times 140 = \text{₹}28$$
$$\text{Selling Price (S.P.)} = 140 - 28 = \text{₹}112$$
$$\text{Profit} = \text{S.P.} - \text{C.P.} = 112 - 100 = \text{₹}12$$
$$\text{Gain Percentage} = \left(\dfrac{12}{100} \times 100\right)\% = 12\%$$
Ans: Overall Gain $= 12\%$.
