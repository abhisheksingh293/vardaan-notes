Computer Networking

1. Introduction to Computer Networking

Computer networking is the interconnection of various computers for the purpose of communication. This communication includes the exchange of data, file transfer with the help of computer systems, software applications, and users.

A network can exist between just two computers or between hundreds and thousands of computers. Two devices are said to be networked when a process in one device is able to exchange information with a process in another device.

Concept

What is a Node?

The computers that are involved in the network that originate, route, and terminate the data are called nodes. The interconnection of these computers is accomplished with a combination of cable or wireless media and networking hardware.

2. Components of a Network

Networking two or more computers together requires a basic understanding of computer hardware and software. The primary components involved in data communication include:

  • Sender: A device that sends a message (text, numbers, pictures, etc.). It is also called the source or transmitter. Normally, a computer is used as a sender.
  • Receiver: A device that receives the message. It is also called the sink. A receiver can be a computer, printer, or another computer-related device.
  • Medium: The physical path that connects the sender and receiver used to transmit data. Examples include copper wire, fiber optic cable, or microwaves. It is also known as a communication channel.

3. Network Topology

A network topology is the arrangement of the various elements (nodes) of a computer network. It indicates how data flows within a network, regardless of its physical design.

Common Network Topologies

  • Star Topology: One of the most common network setups where each of the devices on a network connects to a central hub or switch. Data transferred first comes to the central hub and then goes to the respective system. Easy to install and manage.
  • Ring Topology: All devices are connected to one another in the shape of a closed loop. Each device is connected directly to two other devices. They offer high bandwidth but are on the verge of extinction.
  • Bus Topology: All devices are connected to a central cable called the bus or backbone. It is simple, relatively inexpensive, and easy to install for small networks.
  • Tree Topology: Connects multiple star networks to other star networks along a linear bus backbone. Also referred to as star bus topology.
  • Hybrid Topology: Uses a combination of any two or more basic topologies in a way that the resulting network does not exhibit one of the standard topologies.
Important

Single Point of Failure

In a Star Topology, the hub represents a single point of failure; if the central hub fails, all connected computers disconnect. Similarly, in a Bus Topology, if the main cable fails, all the other connected computers will die.

4. Networking Hardware

Networking hardware includes the important physical components required to create a computer network.

  • Network Interface Cards (NIC): Provides the physical connection between the network and the computer workstation. It determines the speed and performance of a network connection for that specific system.
  • Hub: A network device that sends one signal to all of the stations connected to it. It takes data coming into a port and sends it out to all the other ports.
  • Switch: Splits large networks into small segments, decreasing the number of users sharing the same network resources and bandwidth. It gives two communicating devices a switched connection and helps prevent data collisions.
  • Router: A device that connects any number of LANs. It uses standardized protocols to forward data efficiently to their destination based on the Network Address (IP), not the Hardware (MAC) address.

5. Types of Networks

Networks can be characterized by their physical capacity, organizational purpose, scale, and scope.

  • LAN (Local Area Network): Designed to operate over a small physical area such as an office, factory, or a group of buildings. Privately owned.
  • PAN (Personal Area Network): Used for communication among computer devices in proximity to an individual's body (a few metres). It can be wired (USB) or wireless (Bluetooth).
  • MAN (Metropolitan Area Network): Connects two or more computers that are geographically separated but located in the same metropolitan city.
  • WAN (Wide Area Network): Covers a large geographic area such as a country, continent, or the whole world. It is two or more LANs connected together (e.g., an airline reservation system).
  • CAN (Campus Area Network): An interconnection of LANs within a limited geographical area, usually established in a university campus.

6. Network Protocols

Concept

What is a Protocol?

A protocol is a system of rules that defines how data is transmitted over a network. It is a standardized method for establishing communications between different devices.

  • IP (Internet Protocol): A network-layer protocol that contains addressing information enabling packets to be routed. It represents the heart of internet protocols.
  • TCP (Transmission Control Protocol): Provides reliable transmission of data in an IP environment. It ensures reliable end-to-end packet delivery.
  • HTTP (Hyper Text Transfer Protocol): Controls how Web servers and Web browsers communicate. It is a stateless protocol.
  • FTP (File Transfer Protocol): Provides a method for copying files over a network from one computer to another (uploading and downloading).
  • SMTP (Simple Mail Transfer Protocol): Used for sending e-mail messages between servers across the Internet.
  • IMAP (Internet Message Access Protocol): A standard e-mail protocol that stores e-mail messages on a mail server but allows the user to view and organize them as though they were stored locally.
Fact

The Inventors of TCP/IP

Robert Elliot "Bob" Kahn, an American Internet pioneer, engineer, and computer scientist, along with Vint Cerf, invented the Transmission Control Protocol (TCP) and the Internet Protocol (IP), the fundamental communication protocols at the heart of the Internet.

7. Important Internet Terms

  • Intranet: A private network based on TCP/IP protocols belonging to an organization, accessible only by its authorized members.
  • URL: Stands for Uniform Resource Locator. The fundamental network identification address on the World Wide Web.
  • IP Address: An identifier for a computer or device on a TCP/IP network.
  • ISP: Internet Service Provider. A company that provides customers with internet access (e.g., BSNL, Airtel, Jio).
  • DNS: Domain Name System. Translates domain names (which computers understand) into IP addresses.
  • Web Portal: A website offering a broad range of resources and services like emails, forums, and search engines (e.g., Yahoo).
  • Modem: A network device that modulates and demodulates analog carrier signals for encoding and decoding digital information.
  • Hyperlink / Link: An HTML object attached to text or images that allows a user to jump to a new location.
  • Gateway: A communication device that acts as a "gate" between two networks, allowing traffic to flow in and out.
  • Bandwidth: The capacity of a communications link to transmit the maximum amount of data in a given amount of time (measured in bps).
  • Website & Web Page: A website is a collection of related pages. A web page is a single document/file containing information.

8. Cloud Computing

In computer terminology, Cloud refers to a Network or Internet. Cloud Computing refers to accessing and manipulating hardware and software resources remotely. Instead of using your local system's hardware, it is provided to you as a service over the internet (e.g., Google Docs, Gmail).

Characteristics of Cloud Computing

  • On-demand self-service: Consumers can use facilities without requiring human interaction.
  • Broad Network Access: Completely web-based; accessible from anywhere at any time.
  • Resource Pooling: Provider pools IT resources to serve multiple consumers dynamically.
  • Rapid Elasticity: The ability to deal with increasing or decreasing demand quickly.
  • Measured Usage Service: Keeps track of resource usage and bills consumers accordingly.

Advantages and Disadvantages

  • Benefits: Highly cost-effective (lowers hardware/software costs), regular automated software updates, better computing power, and virtually unlimited storage capacity.
  • Disadvantages: Greater dependency on service providers, privacy and security risks (data is on someone else's system), and a reliable internet connection is strictly required.

Web 2.0

Web 2.0 is a collective term for web-based technologies that allow people to collaborate and share information online via social media, blogging, and social network sites.
