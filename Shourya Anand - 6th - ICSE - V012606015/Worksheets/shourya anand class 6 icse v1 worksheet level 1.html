Section A: Sets (20 Questions)
1.
State whether the collection of all intelligent students in Class 6 is a well-defined set or not.
2.

3.
If $B = \{2, 4, 6, 8, 10\}$, find the cardinal number $n(B)$.
4.

5.
Insert the symbol $\in$ or $\notin$: $7$ _____ $\{1, 3, 5, 7, 9\}$.
6.
Convert the Roster Form $D = \{1, 2, 3, 4, 5\}$ into Set-Builder Form.
7.
Identify if $E = \{x : x \text{ is a multiple of } 5\}$ is a finite or infinite set.
8.

9.

10.
If $X = \{5, 10, 15\}$ and $Y = \{15, 10, 5\}$, state true or false: $X = Y$.
11.
Find the cardinal number $n(S)$ for $S = \{x : x \text{ is a primary color}\}$.
12.
Write the set of prime numbers less than $10$ in Roster form.
13.
Insert $\in$ or $\notin$: $0$ _____ $\{x : x \text{ is a natural number}\}$.
14.

15.

16.

17.
Are $\{0\}$ and $\varnothing$ same? Explain briefly in one word.
18.

19.
Write the cardinal number of an empty set.
20.
State whether the collection of all natural numbers between $15$ and $20$ is a finite set.
