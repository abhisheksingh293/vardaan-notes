MAIL MERGE

1. Introduction to Mail Merge

Concept Mail Merge is a feature in word processing applications (like Microsoft Word) that allows you to create multiple personalized documents, such as letters, labels, or envelopes, each addressed to a different recipient. It combines a template with a database containing the personalized information.

Imagine your class teacher needs to send an invitation letter to the parents of all 40 students for the annual function. Instead of typing the letter 40 times, they can use Mail Merge. They write just one document (template) and then merge it with a list of names and addresses.

Advantages of Mail Merge

  • Saves Time: You can create personalized documents for bulk mailing very quickly.
  • Reduces Errors: You don't have to manually type each recipient's details, reducing typos.
  • Easy to Edit: You need to proofread and make changes to only one document (the main document).
  • Reusable: A common document (template) can be saved and reused later with different data.

2. Components of Mail Merge

The Mail Merge process involves three main components working together:

A. Main Document

This is the document that contains the information that will remain the same in each of the merged documents. It is the template, and it can be a formal letter, an envelope, a label, etc. For example, the body text of an invitation letter.

B. Data Source

The data source is a file that contains the variable information, such as the names, addresses, and phone numbers of the recipients. This information changes in every document. It is essentially a mailing list organized in a tabular form (like a spreadsheet or database). It is also known as the recipient list.

C. Merged Document

This is the final output. When the main document and the data source are combined, Microsoft Word replaces the placeholders (merge fields) in the main document with actual data from the data source. The result is a third document: the merged document, containing personalized copies for everyone.

Important A Merge Field (e.g., <<Name>>, <<Address>>) is a placeholder in the main document that tells Word exactly where to insert the variable data from the data source during the merging process.

3. Steps to Perform Mail Merge

The process of Mail Merge generally involves three basic stages: Creating the main document, creating/specifying the data source, and merging them.

Stage 1: Creating the Main Document

  • Open Microsoft Word and type the common content of your letter.
  • Click on the Mailings tab.
  • Click on the Start Mail Merge drop-down button in the Start Mail Merge group.
  • Select the Step-by-Step Mail Merge Wizard option. The Mail Merge task pane will appear on the right side.
  • Under Select document type, choose Letters and click Next.
  • Under Select starting document, choose Use the current document and click Next.

Stage 2: Creating the Data Source

  • Under Select recipients, if you don't have a list yet, choose the Type a new list radio button and click Create.
  • The New Address List dialog box opens. Enter the details of your recipients here.
  • Click New Entry to add more people. Click OK when finished.
  • Save your new data source file with an appropriate name (e.g., "List of Parents").
Fact You can also use an existing data source, like an Excel spreadsheet or an Access database, instead of typing a new list every time! Just select Use an existing list.

Stage 3: Merging the Document with the Data Source

  • Click Next: Write your letter in the task pane.
  • Place your cursor in the document where you want recipient details to appear.
  • Use options like Address block... or Greeting line... in the task pane to insert merge fields into your document. You will see placeholders like <<AddressBlock>> appear.
  • Click Next: Preview your letters. You will now see actual names and addresses instead of placeholders. You can use the arrows in the task pane to scroll through the merged letters and check them.
  • Click Next: Complete the merge.

4. Printing the Merged Documents

Once you are satisfied with the preview, you can finalize the process.

  • Under the Complete the merge section, click on the Print... option to print out all the personalized letters directly.
  • OR, if you want to make specific changes to individual letters before printing, click on Edit individual letters.... This will generate a new Word document containing all the merged letters on separate pages, which you can save and edit.
