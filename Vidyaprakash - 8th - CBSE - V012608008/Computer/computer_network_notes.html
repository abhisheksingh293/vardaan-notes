COMPUTER NETWORK

1. Introduction to Network

Concept

A Computer network is basically referred to as a group of computers and devices connected to each other with different communication channels. The purpose of a computer network is to communicate with users and allow them to share information, data, and resources.

2. Advantages of Networking

Computer networks are widely used in today's world and provide multiple benefits. Key advantages include:

  • Communication: Enables efficient and easy communication through email, instant messaging, chatrooms, voice calls, and videoconferencing. It allows for quick exchange of data and information.
  • Sharing hardware resources: Users in a networked environment can share devices like printers and scanners. This significantly reduces expenditure as multiple users share single devices.
  • Sharing files, data and information: Authorized users can access data stored on other computers on the network. A common example is the centralized railway database accessed by employees nationwide, which avoids data duplication and ensures security.
  • Sharing software: Software can be shared and programs can be run over the network. Users can also install software from other networked machines.

3. Applications of Networking

Computer networks find applications in various fields:

  • Email: Electronic distribution of messages from one user to recipients via a network.
  • Website: A location connected to the internet maintaining web pages.
  • File Sharing: Making files (e.g., music, video) available to other users over a network.
  • Hardware Sharing: Allowing multiple computers to access hardware resources like printers and scanners.
  • E-commerce: Facilitating trading of products or services using computer networks.
  • News Groups: Internet-based discussion groups focusing on specific topics.
  • Internet Telephony (VoIP): Technology for delivering voice communications over computer networks.
  • Videoconferencing: Conducting conferences between remote participants transmitting audio and video data.
  • Chat Groups & Instant Messenger: Real-time text transmission and online chat platforms.
  • Internet Radio: Audio broadcasting service transmitted through the internet.
  • Remote Access: Gaining access to a networked computer from a remote distance.

4. Components of Computer Network

To set up a computer network, specific components are required:

Fact

As soon as a computer is connected to a network, it is formally called a node or a workstation.

  • Computers (Server or Client workstations): At least two computers are needed to form a network.
  • Network Interface Card (NIC): A crucial component that joins a computer to a network, allowing it to communicate with other networked computers.
  • Connection Medium: Usually a physical wire or cable. However, wireless communication is also prevalent.
  • Network Devices: Devices such as Bridges, Routers, Hubs, and Switches are essential for joining smaller networks to create larger ones.
  • Network Operating System Software: Software like Microsoft Windows, UNIX, or Linux that manages network resources.

5. Types of Networks

Computer networks are classified into different categories based on various factors.

5.1 Based on Area Covered

  • Personal Area Network (PAN): Interconnection of IT devices within the environment of an individual user (e.g., connecting a laptop, cellphone, and wearable devices).
  • Local Area Network (LAN): Confined to a small geographical area, such as a single building or a school (e.g., a school computer lab).
  • Metropolitan Area Network (MAN): Formed by connecting two or more LANs. It is confined to a city or a metropolitan area (e.g., Delhi Metro network, ATM networks).
  • Wide Area Network (WAN): Spans a large geographical area like a state, province, or country. It often connects multiple LANs or MANs. The most popular example is the Internet.

5.2 Based on Network Architecture

Network architecture refers to the structure and organization of hardware and software.

  • Client/Server Networks: A highly efficient, distributed structure. It features a centralized, powerful computer known as the Server which runs programs and shares resources. Other computers connected to it are Clients, which request server content but do not share their own resources. This setup is expensive but robust.
  • Peer-to-Peer Networks: There is no dedicated server or hierarchy. All computers are equal (peers) and can act as both client and server. This is less expensive and better suited for smaller networks.

5.3 Based on Network Topology

Topology refers to the physical or logical arrangement of computers in a network.

  • Bus topology: A single main cable (backbone) carries all data. All devices connect to this backbone. It uses less cabling but the entire network fails if the backbone breaks.
  • Star topology: All computers connect to a central device (Hub or Switch). The central device manages data transfer. It is easy to set up; failure of one node doesn't affect others, but central device failure brings down the network.
  • Ring topology: Devices are connected in a closed loop or ring. Data travels in one direction. Each device handles messages passing through. Failure of a single link generally disrupts the network.
  • Tree topology: A combination of Bus and Star topologies. It allows branching out and multiple servers, ideal for widely spread networks. Not suitable for small networks due to cabling waste.
  • Mesh topology: Every computer is connected to every other computer. Messages take the shortest, easiest route.
Important

The Internet uses a Mesh topology structure, allowing messages to dynamically find the shortest available route to their destination.

5.4 Based on Transmission Media

Transmission media is the pathway data takes from one node to another.

  • Cables: Used for shorter distances. Types include Twisted Pair cable, Coaxial cable, and Fibre Optic cable.
  • Satellites: Used for longer distances where cabling is impossible. They transmit data using radio waves and microwaves.

6. Network Devices

These are hardware components used to connect computers or electronic devices.

  • Hub: A non-intelligent device. It takes input data and broadcasts it to all other ports connected to the network. Only one transmission occurs at a time.
  • Switch: An intelligent device with decision-making capacity. It knows the machine addresses of connected devices and securely sends data only to the intended receiver node.
  • Repeater: Used to amplify and regenerate input signals over long distances, eliminating noise and preventing data loss.
  • Router: Forwards messages based on IP addresses. Essential when multiple devices need to connect to the internet using a single connection.
  • Bridge: A primitive device compared to a switch. It connects network segments but cannot connect to the internet as it lacks IP address knowledge.

7. Wireless Technologies

Communication using electromagnetic waves without physical wires.

  • Bluetooth: Used for building a Personal Area Network (PAN) to exchange data over short distances between devices like phones and laptops.
  • Wi-Fi (Wireless Fidelity): Also known as WLAN. Connects devices to each other and the internet wirelessly. Devices connect via a Wi-Fi hotspot.
  • GPS (Global Positioning System): A satellite-based navigation system using a network of satellites to determine precise locations. Used in mobiles and cars for tracking.
  • Infrared Communication: Uses infrared radiations (longer wavelength than visible light) for communication, common in TV remote controls.
