Section C: Conditional Identities & Evaluation
31.
If $x + \frac{1}{x} = 5$, find $x^2 + \frac{1}{x^2}$ Ans: $(x + \frac{1}{x})^2 = 5^2 \Rightarrow x^2 + 2 + \frac{1}{x^2} = 25 \Rightarrow \mathbf{x^2 + \frac{1}{x^2} = 23}$
32.
If $a - \frac{1}{a} = 4$, find $a^2 + \frac{1}{a^2}$ Ans: $(a - \frac{1}{a})^2 = 4^2 \Rightarrow a^2 - 2 + \frac{1}{a^2} = 16 \Rightarrow \mathbf{a^2 + \frac{1}{a^2} = 18}$
33.
If $y + \frac{1}{y} = 3$, find $y^4 + \frac{1}{y^4}$ Ans: $y^2 + \frac{1}{y^2} = 9-2 = 7 \Rightarrow (y^2 + \frac{1}{y^2})^2 = 49 \Rightarrow y^4 + 2 + \frac{1}{y^4} = 49 \Rightarrow \mathbf{y^4 + \frac{1}{y^4} = 47}$
34.
If $p - \frac{1}{p} = 2$, find $p^4 + \frac{1}{p^4}$ Ans: $p^2 + \frac{1}{p^2} = 4+2 = 6 \Rightarrow (p^2 + \frac{1}{p^2})^2 = 36 \Rightarrow p^4 + 2 + \frac{1}{p^4} = 36 \Rightarrow \mathbf{p^4 + \frac{1}{p^4} = 34}$
35.
If $x + y = 7$ and $xy = 12$, find $x^2 + y^2$ Ans: $x^2 + y^2 = (x+y)^2 - 2xy = (7)^2 - 2(12) = 49 - 24 = \mathbf{25}$
36.
If $a - b = 3$ and $ab = 10$, find $a^2 + b^2$ Ans: $a^2 + b^2 = (a-b)^2 + 2ab = (3)^2 + 2(10) = 9 + 20 = \mathbf{29}$
37.
If $m^2 + \frac{1}{m^2} = 23$, find $m + \frac{1}{m}$ ($m>0$) Ans: $(m + \frac{1}{m})^2 = m^2 + \frac{1}{m^2} + 2 = 23 + 2 = 25 \Rightarrow \mathbf{m + \frac{1}{m} = 5}$
38.
If $x^2 + \frac{1}{x^2} = 27$, find $x - \frac{1}{x}$ ($x>0$) Ans: $(x - \frac{1}{x})^2 = x^2 + \frac{1}{x^2} - 2 = 27 - 2 = 25 \Rightarrow \mathbf{x - \frac{1}{x} = 5}$
39.
If $a + b = 9$ and $a^2 + b^2 = 41$, find $ab$ Ans: $(a+b)^2 = a^2+b^2+2ab \Rightarrow 81 = 41 + 2ab \Rightarrow 2ab = 40 \Rightarrow \mathbf{ab = 20}$
40.
If $x - y = 4$ and $x^2 + y^2 = 40$, find $xy$ Ans: $(x-y)^2 = x^2+y^2-2xy \Rightarrow 16 = 40 - 2xy \Rightarrow 2xy = 24 \Rightarrow \mathbf{xy = 12}$
41.
If $3x + 2y = 12$ & $xy = 6$, find $9x^2 + 4y^2$ Ans: $(3x+2y)^2 = 9x^2 + 4y^2 + 12xy \Rightarrow 144 = 9x^2 + 4y^2 + 12(6) \Rightarrow 144 = 9x^2 + 4y^2 + 72 \Rightarrow \mathbf{9x^2 + 4y^2 = 72}$
42.
If $4a - 3b = 5$ & $ab = 2$, find $16a^2 + 9b^2$ Ans: $(4a-3b)^2 = 16a^2 + 9b^2 - 24ab \Rightarrow 25 = 16a^2 + 9b^2 - 24(2) \Rightarrow 25 + 48 = \mathbf{16a^2 + 9b^2 = 73}$
43.
Find $(x+y)^2$ if $x^2+y^2=13$ and $xy=6$ Ans: $(x+y)^2 = (x^2+y^2) + 2xy = 13 + 2(6) = 13 + 12 = \mathbf{25}$
44.
Find $(a-b)^2$ if $a^2+b^2=25$ and $ab=12$ Ans: $(a-b)^2 = (a^2+b^2) - 2ab = 25 - 2(12) = 25 - 24 = \mathbf{1}$
45.
If $x^4 + \frac{1}{x^4} = 47$, find $x^2 + \frac{1}{x^2}$ Ans: $(x^2 + \frac{1}{x^2})^2 = x^4 + \frac{1}{x^4} + 2 = 47 + 2 = 49 \Rightarrow \mathbf{x^2 + \frac{1}{x^2} = 7}$
